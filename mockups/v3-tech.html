Éthique by design

Conçu pour respecter les utilisateurs.

Pas d'algorithme qui exploite l'attention. Pas de tracking publicitaire. Pas de revente de données. Notre éthique n'est pas un argument marketing — c'est un choix d'architecture.

🛡️

Modération préventive

Tous les médias passent par Sightengine (IA spécialisée) avant publication. Détection nudité, violence, drogue, haine. Paramètre do_not_store=1 activé : les médias ne sont jamais conservés par le prestataire.

🎙️

Pas de modération vocale automatique

Surveiller la voix de quelqu'un est une frontière qu'on ne franchit pas. La modération audio se fait via signalement par la communauté.

🌍

Langage inclusif obligatoire

Toute l'app utilise "celles et ceux", "elles et ils". Pas de masculin générique. Question de respect, pas de wokisme.

🚫

Aucun pixel de tracking tiers

Pas de Meta Pixel, pas de Google Ads, pas de remarketing. Nos analytics (PostHog) servent à améliorer le produit, pas à vendre votre profil.

⏱️

Plafonds anti-addiction

Cap quotidien sur les points (400/jour, 300 si Top 3) pour empêcher les marathons. L'app récompense la régularité, pas le burn-out.

🔐

RGPD conformes par design

Suppression compte en 24h, données minimales collectées, hébergement Supabase EU (Francfort). Mention légale et CGU complets.

Sécurité
de production.

L'app a été auditée techniquement avant chaque release majeure. RLS Supabase actif sur toutes les tables sensibles, triggers anti-fraude, validation server-side systématique.

  • Row Level Security PostgreSQL — chaque user voit ses propres données
  • Triggers anti-fraude — manipulation de classement bloquée et auditée
  • Validation côté serveur (Edge Functions Deno) sur tous les flux critiques
  • Cron de modération 24/7 + signalements communautaires
  • Captcha Cloudflare Turnstile à l'inscription
  • JWT révocables par session (active_session_id)
